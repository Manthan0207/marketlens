# StockScope — Evidence-based Stock Research

A Python research workspace combining an interactive dashboard, deterministic financial analytics, and a tool-using AI assistant. Reviewers can explore the offline demo without credentials; live mode connects to Yahoo Finance, Serper news, and a Hugging Face model endpoint.

## What it demonstrates

- **Agent orchestration:** LangGraph routes model tool calls through four MCP tools, with a bounded execution loop and inspectable tool arguments.
- **Reliable arithmetic:** Python calculates observed return, closing-price maximum drawdown, annualized daily-return volatility, and SMA20. The model receives calculated metrics.
- **Comparable evidence:** Stock comparisons align overlapping trading dates and preserve individual provider errors.
- **Persistent state:** SQLite checkpoints let users resume conversations by session ID across process restarts.
- **Usable interface:** Streamlit provides price and volume charts, metric cards, comparison tables, research chat, and CSV/Markdown downloads.
- **Reproducible validation:** Offline tests cover known metrics, missing data, provider failures, tool routing, conversation persistence, and dashboard rendering. A GitHub Actions workflow runs these checks.

## Quick start: no credentials

Use Python 3.12. From the project directory:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The dashboard starts in **Offline demo**. All displayed demo prices and comparisons are explicitly synthetic. The demo report is deterministic and does not claim to be generated by a live model.

On macOS/Linux, activate with `source .venv/bin/activate` instead.

## Enable live research

Copy `.env.example` to `.env` if you do not already have one. Set `HF_TOKEN` for the model and `SERPER_API_KEY` for news. Price charts and comparisons can run without either credential. Existing environment variables take precedence over `.env`; `HF_MODEL` and `HF_BASE_URL` customize the model endpoint.

Switch the dashboard to **Live research**, or use the CLI:

```powershell
python check_tools.py
python run.py "Compare AVANTEL.NS and INFY.NS over three months" --thread research-session --chat
python run.py "Summarize our earlier findings" --thread research-session
```

`check_tools.py` discovers MCP tools without contacting the model or market data providers. Live research requires network access and a model with tool-calling support. Credentials and SQLite files are excluded from Git.

## Data flow

```text
Streamlit dashboard ──► price/news tools ──► Yahoo Finance / Serper
                  └──► research session ──► LangGraph agent
CLI ─────────────────► research session       │       ▲
                                              ▼       │
                                         MCP ToolNode
                                              │
                                         custom_mcp.py
                                              │
                                         analytics.py

SQLite ◄────────────── LangGraph conversation checkpoints
```

The dashboard invokes the shared tool functions directly for charts. The AI assistant accesses those functions through a separate local MCP subprocess. Tool-call traces identify what evidence the agent requested; they do not expose model reasoning.

## Project map

| File | Responsibility |
| --- | --- |
| `app.py` | Dashboard, five-minute UI cache, exports, chat |
| `analytics.py` | Pure numerical calculations |
| `custom_mcp.py` | Provider access and MCP tool registration |
| `graph.py` | Model configuration and agent/tool routing |
| `research.py` | SQLite lifecycle, saved history, execution trace |
| `run.py` | Single-question and interactive CLI |
| `demo.py` | Reproducible synthetic data and example report |
| `tests/` | Offline regression and integration checks |

StockScope does not execute trades or access brokerage accounts.

## Validation

```powershell
python -m unittest discover -s tests -v
python -m compileall -q app.py analytics.py custom_mcp.py demo.py graph.py research.py run.py
python check_tools.py
```

The agent integration test substitutes a deterministic model and fixture tool while exercising the real LangGraph loop and SQLite checkpointer. Dashboard tests use [Streamlit AppTest](https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest); persistence uses [LangGraph AsyncSqliteSaver](https://reference.langchain.com/python/langgraph.checkpoint.sqlite/aio/AsyncSqliteSaver).

## Calculation rules and practical limits

- Return is `(last close / first close - 1) × 100` over actual observations. The requested period may start on a non-trading day.
- Drawdown uses closing prices, not intraday highs/lows. Volatility uses sample standard deviation of simple daily returns multiplied by √252; at least three closes are needed.
- SMA20 requires 20 observations. Missing metrics remain unavailable rather than becoming invented numbers.
- Live price history is adjusted by yfinance. Demo values are synthetic. Provider data can be delayed or incomplete.
- Comparisons use local-currency percentage returns with no FX conversion. Failed tickers are reported separately.
- The dashboard caches successful and failed price lookups for five minutes. Live AI tool calls fetch from providers directly.
- Sessions accumulate history and have no automatic summarization. SQLite is intended for a local demo, with no authentication or multi-user access controls. Users sharing the app can access a session if they know its ID.
- The agent is instructed to treat retrieved content as untrusted data; this is a prompt constraint, not a complete defense against prompt injection.
- Offline tests do not establish live provider uptime, investment usefulness, or model accuracy. The assistant is a research aid, not an investment recommendation service.
